✦ ابزار محلی رمزنگاری PARNIKA

این ابزار محتوای JSON را در مرورگر با PBKDF2 + AES-256-GCM رمزنگاری می‌کند. هیچ چیزی به سرور ارسال نمی‌شود.

رمز را در این ابزار انتخاب کن و هر دو فایل letters و gifts را با همان رمز بساز. رمز واقعی را داخل مخزن عمومی ذخیره نکن. برای امنیت بهتر از عبارت طولانی و غیرقابل حدس استفاده کن.

نمونه‌ی ساختار نامه‌ها

{
  "letters": [
    {
      "title": "عنوان نامه",
      "preview": "پیش‌نمایش کوتاه",
      "body": "متن کامل نامه"
    }
  ]
}

نمونه‌ی ساختار هدیه‌ها

{
  "gifts": [
    {
      "title": "عنوان هدیه",
      "description": "توضیح کوتاه",
      "emoji": "🎁",
      "glow": "#9de7ff",
      "letter": "نامه‌ی داخل هدیه"
    }
  ]
}
