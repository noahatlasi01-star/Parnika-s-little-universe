جهانی کوچک برای تو — نسخه‌ی عاشقانه و موبایل‌پسند 💙
===================================================

اجرا:
۱) فایل ZIP را استخراج کن.
۲) index.html را باز کن.
۳) برای اجرا با Node.js در ترمینال پوشه بنویس:
   node server.js
   سپس http://localhost:3000 را باز کن.

شروع و موسیقی:
سایت با یک صفحه‌ی خوش‌آمدگویی رمانتیک باز می‌شود. روی «بیا با هم واردش بشیم» بزن؛ همان لمس، اجازه‌ی لازم مرورگر برای پخش موسیقی را فراهم می‌کند و ملودی آرام شروع می‌شود.
نکته: مرورگرهای موبایل معمولاً اجازه نمی‌دهند صدای سایت بدون هیچ لمس یا تعاملی خودکار پخش شود. بنابراین شروع موسیقی با لمس اولین دکمه، مطمئن‌ترین راه است.

شخصی‌سازی:
فایل script.js را باز کن و CONFIG ابتدای فایل را تغییر بده:
- recipientName: اسم یا لقب او
- senderName: اسم یا لقب تو
- personalMessage: متن نامه
- secretMessage: پیام مخفی تولد

موبایل:
طراحی واکنش‌گراست و برای نمایشگرهای باریک تنظیم شده است. برای تست واقعی، در گوشی هم بازش کن.
برای فرستادن لینک به او باید سایت را روی یک میزبان عمومی مثل GitHub Pages منتشر کنی؛ localhost فقط روی دستگاه خودت باز می‌شود.

محتویات:
index.html — ساختار و متن فارسی
style.css — ظاهر، انیمیشن و نسخه‌ی موبایل
script.js — تعامل‌ها، پیام‌ها و موسیقی ساخته‌شده با Web Audio
server.js — سرور محلی Node.js
