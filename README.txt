دنیای آبی تو — هدیه‌ی تعاملی موبایل‌محور

1) ZIP را استخراج کن.
2) ترمینال را داخل پوشه باز کن.
3) اجرا کن: node server.js
4) در مرورگر برو به: http://localhost:3000

قابلیت‌ها: طراحی موبایل‌محور، گل SVG تعاملی، موسیقی تولیدشده با Web Audio پس از لمس، ۵ معما، نامه و پیام مخفی، جعبه‌ی آرزوها با ذخیره‌ی محلی و خروجی متنی، پیام‌های انگیزشی، بازی پیدا کردن ۶ ستاره.

برای ارسال لینک به دیگران، پروژه را روی هاست عمومی منتشر کن. localhost فقط روی دستگاه خودت باز می‌شود. آرزوها در مرورگر همان دستگاه ذخیره می‌شوند. فونت آنلاین است و در صورت نبود اینترنت فونت جایگزین استفاده می‌شود.
