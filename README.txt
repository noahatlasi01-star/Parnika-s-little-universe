جهانی کوچک برای تو — نسخه‌ی بازطراحی‌شده برای موبایل

ویژگی‌ها:
- طراحی mobile-first با پشتیبانی از safe-area گوشی و نوار پایین
- صفحه‌ی خوش‌آمدگویی و موسیقی ساخته‌شده با Web Audio (بدون فایل صوتی خارجی)
- بخش گل آبی با غنچه/شکوفایی، پیام‌ها، نامه، ستاره‌ها و آرزو
- پنجره‌های بازشونده مناسب لمس، دکمه بستن و بستن با Escape
- بدون نیاز به نصب پکیج؛ فقط Node.js برای اجرای سرور محلی

اجرا:
1. ZIP را استخراج کن.
2. داخل پوشه، ترمینال را باز کن.
3. اجرا کن: node server.js
4. در مرورگر باز کن: http://localhost:3000

نکته‌ها:
- صدا به خاطر محدودیت مرورگرها بعد از لمس دکمه‌ی ورود شروع می‌شود.
- برای دیدن سایت از گوشی در شبکه‌ی محلی، رایانه و گوشی باید روی یک Wi-Fi باشند و از IP محلی رایانه به‌جای localhost استفاده شود.
- برای فرستادن لینک به شخص دیگر، سایت باید روی یک هاست عمومی منتشر شود.
- ظاهر برای موبایل طراحی شده؛ با این حال، تست نهایی روی مدل گوشی و مرورگر شما لازم است.
