چک‌لیست انتشار PARNIKA
1) فایل ZIP را استخراج کن.
2) در حالت محلی با `python -m http.server 8000` اجرا کن.
3) رمز نمونه parnika-demo فقط برای تست است؛ قبل از محتوای شخصی آن را عوض کن.
4) ابزار tools/encrypt.html را برای ساخت دوباره‌ی هر دو فایل رمزنگاری‌شده استفاده کن.
5) فقط فایل‌های رمزنگاری‌شده و متن‌های عمومی را روی GitHub قرار بده.
6) در تنظیمات GitHub → Pages، branch و پوشه‌ی حاوی index.html را انتخاب کن.
7) فعلاً ارسال آرزو به تلگرام وصل نیست؛ مرحله‌ی بعد API امن روی Pxxl ساخته می‌شود.
